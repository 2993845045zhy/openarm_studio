> 三部分：① 后端当前用到的接口（按层）② 已安装但还没用的能力（后续开发可用）

## 一、后端当前用到的接口

### 1. `openarm_can` 1.4.1（Python 绑定，最底层）

| 接口 | 用在哪 |
|---|---|
| `oa.OpenArm(iface, use_fd=True)` | probe_bus / driver 内部 |
| `oa.MotorType.DM8009/DM4340/DM4310` | 电机类型表 |
| `oa.CallbackMode.STATE` | 回调模式（只收状态帧） |
| `oa.MITParam(kp, kd, q, dq, tau)` | **软模式帧**（重力补偿/示教/关节阻抗）唯一控制通道 |
| `OpenArm.init_arm_motors(types, send_ids, recv_ids)` | probe_bus 裸探测 |
| `OpenArm.refresh_all()` / `recv_all(timeout_us)` | 状态轮询（recv_all 补读是关键，官方 300µs 读不全 8 轴） |
| `OpenArm.enable_all()` / `disable_all()` | estop / 兜底失能 |
| `ArmComponent.mit_control_all([...])` | 软模式帧下发 7 关节 |
| `ArmComponent.get_link_stats(i)` | 总线体检（responses/commands_sent） |
| `ArmComponent.get_motors()` | probe_bus 读裸位置 |
| `GripperComponent.set_position(rad, speed_rad_s, torque_pu)` | 夹爪 POS_FORCE（速度/电流限幅内建） |

### 2. `openarm_driver` 0.5.1（Python 高层，位置模式）

| 接口 | 用在哪 |
|---|---|
| `Config(name)` + `cfg._config` 补丁 | 连接时修左臂 joint8 限位 |
| `SingleArmDriver(arm_side, config, can_interface)` | 每臂一个 |
| `drv.start()` / `drv.stop()` | 使能（含起始轨迹）/ 失能（含回程） |
| `drv.send_position(arr)` | **位置模式唯一通道**（官方安全链：限位→单步→速度） |
| `drv.smooth_move(pos, hz, duration)` | 插值运动 |
| `drv.set_latest_state(timeout_us)` + `drv.latest_state` | 状态缓存（qpos/qvel/qtorque/tmos/trotor） |
| `drv.config.get_*()` | joint_limits / offsets / delta / velocity / kps / kds / start / stop |
| `drv.kps` `drv.kds` `drv.joint_offsets` | 实例属性直读 |
| `drv.last_command` / `last_command_time_s` | `_travel` 插值基准 + 每帧回写 |
| `drv.safety_stop_reason` | 安全锁存显示 |
| `drv.get_health()` | 1Hz 健康快照 |
| `drv._on_start/_on_stop` | **我们重写**为 `_travel`（逐帧补读版） |

### 3. `openarm_control` 0.6.0（IK，backend/ik.py）

| 接口 | 用在哪 |
|---|---|
| `ArmSetup.from_args(xml, mode, frame_*, keyframe, origin_frame)` | v1 MJCF 双臂装配 |

| `Kinematics(setup, params)` | 求解器 |
| `kin.fk(side, q8)` / `kin.set_target(side, pose)` / `kin.solve()` | FK / 迭代式 QP IK |

### 4. `mujoco` 3.12.0（模型与渲染）

| 接口 | 用在哪 |
|---|---|
| `MjModel.from_xml_path/from_xml_string` | 官方 v1 模型 / Studio 自建孪生 |
| `mj_forward` + `d.qfrc_bias` | **重力矩**（官方 v1 模型，首选后端） |
| `mj_jac` + `d.xpos` | 末端平动雅可比（碰撞检测/末端力预留） |

## 二、已安装但还没用（后续开发可用）

### openarm_can 里躺着的能力

| 接口 | 干什么用 | 潜在用途 |
|---|---|---|
| `PosVelParam(q, dq)` + `posvel_control_all` | 位置+速度模式，无力矩 | 不需要前馈的简单运动 |
| `VelParam(dq)` + `vel_control_all` | 纯速度环 | 连续旋转/恒速测试 |
| `PosForceParam(q, dq, i)` + `posforce_control_all`（臂关节） | 位置+电流限幅 | **臂关节的柔顺抓取**（现在只有夹爪在用这个模式） |
| `set_control_mode_one/all(ControlMode)` | 运行中切控制模式 | 单关节换模式（如腕关节用 POS_FORCE） |
| `query_param_all(rid)` + `Motor.get_param(rid)` | 读电机寄存器（TMAX/VMAX/KP_ASR…） | 力矩上限在线调、驱动参数巡检 |
| CLI `read/write-motor-param` | 写寄存器（+save 入 Flash，限 1 万次） | 标定 TMAX、改内部环增益 |
| `Motor.is_enabled/get_error_code/has_error` + `motor_error_to_string` | 电机级状态 | 掉线诊断 UI（错误码翻译） |
| `get_bus_status()` ErrorCounter（carrier/tx_overflow…） | 总线错误分类 | 左臂 can1 问题的定量证据 |
| `is_link_running()` / `get_unmatched_frames()` | 链路活性 | 替代"responses>0"的在线判活 |
| `OpenArm.set_zero_all()` / `GripperComponent.set_zero()` | 电位器清零 | 换电机/重标定 |
| `GripperComponent.set_limit(speed, torque)` / `set_position_mit()` | 夹爪限幅在线调 / MIT 模式 | 按物体调夹持力 |
| `CANSocket.write/read_can_frame` + `DMCANDevice.create_can_frame` | 裸帧收发 | 自定义协议/嗅探 |

### driver 里躺着的能力

| 接口 | 潜在用途 |
|---|---|
| `fetch_velocity/torque/mos_temperature/rotor_temperature` | 直接拉取（我们用缓存版即可） |
| `CompositeChecker` 自定义安全链 | 加"力矩突增"检查器（碰撞检测的官方挂点） |
| `drv.kps[i] = ...` 运行时可写 | 在线调位置模式刚度 |

### mujoco 里躺着的能力

| 接口 | 潜在用途 |
|---|---|
| `enable_depth_rendering()`（实测 4.6ms/帧） | 景深虚化、碰撞检测的深度输入、抓取点估计 |
| `mj_fullM`（质量矩阵） | 操作空间惯性 λ、导纳/阻抗的 Λ 矩阵 |
| `d.qfrc_bias` 含科氏项（qvel≠0 时） | 高速段的完整前馈 |
| 渲染器 segmentation | 自动标注数据集（模仿学习） |

## 三、Studio 自己封装的接口（二次开发入口）

### DriverArm（每臂实例，`backend/driver_arm.py`）

```python
arm = DriverArm("right", "can0", config_name="openarm_pedestal", on_log=cb)
arm.connect() / disconnect()
arm.enable() / disable() / estop()          # 异步，投队列
arm.set_targets({"openarm_right_joint1": 0.5, ...})   # 位置模式（安全链内）
arm.smooth_move(named, hz, duration, done=cb)
arm.move_start(done=cb) / move_park(done=cb)          # 完成回调（新）
arm.set_gravity_comp(on, scale, kp_floor)  # kp<2 = 示教（零重力拖动）
arm.set_joint_impedance(on, stiffness, zeta)          # 连续刚度+阻尼比
arm.set_friction_comp(on)
# 状态（线程安全快照）
arm.positions() / torques() / velocities() / temps() / health / rate
arm.connected / enabled / safety_stop_reason / gravity_active
```

### 模块级函数

```python
probe_bus("can0", rounds=5)   # 只读总线体检
can_ifstate("can0")           # {"exists","up","fd"} 接口三态
```

### GravityModel（单例，`backend/gravity.py`）

```python
g = GravityModel.shared()
g.gravity(side, q7)      # 重力矩（官方 v1 MuJoCo 优先，KDL 回退）
g.friction(side, qvel7)  # tanh 摩擦（官方标定参数）
g.jacobian(side, q7)     # 3×7 末端平动雅可比
g.ee_position(side, q7)  # 末端世界坐标
```

### ArmIK（单例，`backend/ik.py`）

```python
ik = ArmIK.shared()
pose7 = ik.fk("right", q8)                    # [x,y,z,qw,qx,qy,qz]
q8   = ik.ik("right", pose7, other_q8=q8_left, iters=8)
```

### RenderWorker（3D 线程，`ui/shell.py`）

```python
w.set_pose(dict)            # 50Hz 推姿态
w.set_metallic(bool)        # 金属质感（重建模型 ~0.2s）
w.play_trajectory(names, points, speed) / stop_trajectory()
w.positions() / ee_pose(side)
model_scene.build_model(cache, theme, metallic=...)
```

## 四、必须记住的硬约束

| 约束 | 值 | 后果 |
|---|---|---|
| MIT 帧 kp 编码 | 0–500 | 超了静默截断 |
| MIT 帧 kd 编码 | **0–5** | ×2 后 J1 的 5.5 历史上一直被截成 5.0 |
| MIT tau 编码 | ±tMax（54/28/10 Nm 按电机型号） | 前馈超限截断 |
| 软模式帧 | **绕过全部官方安全链** | 我们自己补了限速+限位（`_clamp_hold_target`） |
| `recv_all` 官方默认 300µs | 读不全 8 轴 | 全部补读点用 800–4000µs |
| driver 非线程安全 | 唯一控制线程拥有 | UI 只能投队列+读缓存 |
| Studio 与 ros2_control | 不能同时开同一条 CAN | 互相 500Hz 抢总线 |

## 五、后续开发优先级建议

1. **碰撞 trip**：`qtorque` 缓存 − `g.gravity()` − `g.friction()` → `g.jacobian()` 映射末端力 → 超限冻结（全部接口已就绪，只差组装）
2. **力矩标定固化**：`probe` 式只读脚本 + `fetch_torque` 逐关节 scale 表
3. **`posforce_control_all` 用于臂关节**：抓取任务的柔顺位置+限力
4. **深度渲染**：抓取点估计 / 自动标注（性能已验证）
5. **左臂诊断 UI**：`get_bus_status()` 错误分类 + `motor_error_to_string` 翻译
